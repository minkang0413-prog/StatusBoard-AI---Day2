# StatusBoard-AI---Day2

## Day 2: Deploying and Testing an AI-Powered Status Board

This project is part of Day 2 of the robotics and AI workshop. The main focus of this session was learning how to set up, run, test, and prepare an AI-powered application for deployment.

StatusBoard-AI is an application health monitoring dashboard that combines a React frontend, FastAPI backend, database, and AIOps diagnosis system. The application allows users to monitor system health, view logs and incidents, simulate errors, and receive automated diagnoses and suggested fixes.

### Project Structure

```text
StatusBoard-AI
├── backend
└── frontend
```

The **backend** handles APIs, database operations, incidents, logs, and AI diagnosis.

The **frontend** provides the dashboard interface where users can view system health and interact with the application.

### Testing

The application can be tested by viewing system status, checking logs and incidents, and simulating different problems such as API, database, latency, and configuration errors.
